# سناریوی ارائهٔ ۵ دقیقه‌ای

این سناریو برای دفاع دانشگاهی یا معرفی پروژه در مصاحبه طراحی شده است. ستون اصلی ارائه، **دموی تعاملی زنده** است و CLI فقط نقش پشتیبان دارد:

> ▶️ **دموی زنده:** https://mahan-vzmz.github.io/Wumpus-World/demo/
>
> 🔌 **پلن B (بدون اینترنت):** دمو یک فایل HTML خودکفا و بدون هیچ وابستگی خارجی است؛ کافی است `docs/demo/index.html` را در مرورگر باز کنید (دابل‌کلیک).

## پیش از ارائه (چک‌لیست)

- لینک دموی زنده را یک بار باز کنید و مطمئن شوید هر ۶ نقشه و سوییچر MIND کار می‌کنند؛ برای پلن B یک کپی محلی از repo داشته باشید.
- اگر می‌خواهید بخش CLI را هم زنده اجرا کنید، محیط را از قبل آماده کنید:

```bash
python -m pip install -e ".[dev]"
python -m wumpus train          # مدل ML عمداً در git نیست؛ برای عامل ml و بازساخت دمو لازم است
pytest -p no:cov                # چک سریع سلامت — ۱۵۸ تست باید سبز باشد
```

## دقیقهٔ ۰ تا ۱ — مسئله و قرارداد

- محیط `8×8`؛ شروع از `(1,1)`؛ **برد یعنی زنده رسیدن به خروج** (جمع‌کردن طلا اختیاری است).
- خطرها پنهان‌اند: چاه جان را نصف می‌کند، غول مرگ آنی است. عامل آنلاین فقط ادراک محلی دارد: `breeze` (چاه در همسایگی) و `stench` (غول در همسایگی).
- پنج عامل — A\*، قاعده‌محور، Random Forest، و دو baseline (Greedy و Random) — روی **یک موتور قطعی مشترک و یک قرارداد امتیاز** اجرا می‌شوند.
- همان اول شفاف بگویید: **A\* نقشه را کامل می‌بیند؛ کران بالای عملکرد و «خبره» است، نه رقیب هم‌شرایط.** مقایسهٔ منصفانه فقط میان عامل‌های دید-ناقص است.

## دقیقهٔ ۱ تا ۳ — دموی زنده: داخل ذهن AI

لینک دمو را باز کنید. صفحه با نقشهٔ **First Steps** و ذهن **RULE-BASED** شروع می‌شود.

۱. **نقشهٔ باور زنده:** Play را بزنید (کلید Space). گرید سمت چپ باورِ پایگاه دانش است، نه حقیقت نقشه: امن / چاهِ مشکوک / غولِ مشکوک / قطعی. هم‌زمان در **MIND LOG** سمت راست، همان factها و قاعده‌هایی که تصمیم را ساخته‌اند دیده می‌شوند (`NO_BREEZE` → استنتاج `SAFE` → انتخاب frontier). پیام: **تصمیم‌ها قابل‌توضیح‌اند، نه جعبه‌سیاه.**
۲. **لحظهٔ X-ray:** کلید X را بزنید تا حقیقت پنهان نقشه روی باور عامل بیفتد — «عامل فقط این‌قدر می‌داند و با همین می‌جنگد». روی نقشهٔ **Pit Field** این کنتراست از همه گویاتر است (عامل قاعده‌محور با احتیاط کامل در ۳۶ گام می‌برد).
۳. **سوییچ MIND به A\* SEARCH:** نشان «FULL MAP» و X-ray همیشه‌روشن یعنی این عامل هم‌شرایط بقیه نیست؛ در پنل آمار برنامه‌ریز، طول نقشهٔ راه، امتیاز پیش‌بینی‌شده و تعداد nodeهای گسترش‌یافته دیده می‌شود.
۴. **اوج ارائه — تب Last Stand (💀):**
   - با ذهن **RULE-BASED**: عامل طبق اصل «غول هرگز داوطلبانه»، حاضر به عبور از خانه‌های مشکوک به غول نمی‌شود. در MIND LOG لحظهٔ کلیدی را نشان دهید: `P1 EMERGENCY RETREAT: health=2, min_exit_dist=7` — دو واحد جان مانده و خروج ۷ گام دورتر است. در گام ۲۵ جانش تمام می‌شود. **شکستی صادقانه و کاملاً قابل‌توضیح.**
   - حالا MIND را به **ML FOREST** سوییچ کنید: **همان نقشه، برد در ۱۴ گام.** سیاست یادگرفته‌شده ریسک را طور دیگری برمی‌دارد.
   - جملهٔ کلیدی: «تفاوت پارادایم‌ها فقط عدد نیست؛ **شخصیت تصمیم‌گیری** است.»

میان‌برها: `Space` پخش/توقف · `→/←` گام جلو/عقب · `R` شروع دوباره · `X` عکس‌برداری از حقیقت. اگر شنونده خودش کاوش کرد، بدانید ML دو نقشهٔ میانی (Wumpus Lair و The Gauntlet) را با فرسایش جان می‌بازد — ولی حتی آنجا هم به لطف ماسک‌گذاری، **هرگز به غول برخورد نمی‌کند**.

## دقیقهٔ ۳ تا ۴ — اعداد: بنچمارک با فاصلهٔ اطمینان

ارزیابی نهایی روی ۲۰ نقشهٔ holdout جدا × ۵ seed مستقل = **۱۰۰ episode برای هر عامل**؛ فاصلهٔ اطمینان ۹۵٪ با bootstrap روی نقشه‌ها:

| عامل | دید | نرخ برد (۹۵٪ CI) | امتیاز تشخیصی | ورود به چاه | مرگ با غول |
| :--- | :---: | :---: | ---: | ---: | ---: |
| A\* Search | Full | **100%** [100–100] | 41.6 | 0 | 0 |
| Rule-based | Partial | **95%** [85–100] | 24.3 | 7 | 0 |
| Greedy | Partial | 78% [65–88] | 21.6 | 37 | 19 |
| Random Forest | Partial | 70% [50–90] | 13.7 | 35 | **0** |
| Random | Partial | 0% [0–0] | -3.6 | 71 | 15 |

سه پیام این جدول:

1. **عامل قاعده‌محور بهترین عامل آنلاین است** — ۹۵٪ با CI `[85–100]`، بدون هیچ مرگ با غول.
2. **صداقت آماری:** CIهای Random Forest `[50–90]` و Greedy `[65–88]` همپوشانی زیادی دارند؛ پس با ۲۰ نقشه **نمی‌توان ادعا کرد ML قطعاً از baseline ضعیف‌تر است**. این را خودتان بگویید، قبل از این که بپرسند.
3. **ایمنی قابل‌مهندسی است:** ماسک‌گذاری آگاه از خطر، مرگ با غول عامل ML را به صفر رسانده؛ Greedy با ۱۹ مرگ، بهای بی‌اعتنایی به دانش را می‌دهد.

## دقیقهٔ ۴ تا ۵ — زیر کاپوت: مهندسی و داستان باگ

- **معماری لایه‌ای:** `core` (موتور قطعی، مستقل از AI) → `ai` (جست‌وجو/دانش/ML) → `agents` (پشت یک Protocol مشترک) → `evaluation`/`viz`.
- **کیفیت:** ۱۵۸ تست خودکار · پوشش ۹۴.۴۵٪ کد هسته · `ruff` تمیز · CI روی Python 3.11 و 3.12.
- **داستان قوی برای مصاحبه:** یک بازبینی خصمانه (adversarial) سه باگ منطقی واقعی در پایگاه دانش پیدا کرد که تست‌های سبز نگرفته بودند. نمونه: اگر KB **قبل از** پردازش percept از ورود عامل به چاه باخبر نمی‌شد، نسیمِ همان چاه باعث می‌شد یک خانهٔ بی‌گناه (در یک مورد، خانهٔ طلا!) به‌اشتباه «چاه قطعی» اعلام شود — این خطا در **۱۳ از ۱۰۰ نقشه** رخ می‌داد و فقط با راستی‌آزمایی تجربی، نه استدلال، کشف شد. هر رفع باگ یک تست رگرسیون گرفت و کل زنجیرهٔ `dataset → train → benchmark → demo` بازتولید شد.
- **بازتولیدپذیری:** همهٔ اجراها seed صریح دارند؛ نتایج خام، SHA-256 مدل و مشخصات محیط در [`results/`](../results/) ثبت شده‌اند.

## پرسش‌های محتمل (پاسخ کوتاه)

- **«چرا ML از Greedy ضعیف‌تر است؟»** — معنی‌دار نیست؛ CIها همپوشانی دارند. ضعف واقعی ML ریشه در تقلید صرف از مسیر بهینهٔ خبرهٔ full-map دارد (covariate shift)؛ مسیر بهبود شناخته‌شده: DAgger.
- **«اگر A\* رقیب نیست چرا در جدول است؟»** — هم کران بالای عملکرد است، هم مولد برچسب‌های دیتاست ML؛ حذفش گزارش را ناقص می‌کرد.
- **«چرا glitter در تصمیم‌ها دیده نمی‌شود؟»** — طلا هنگام ورود خودکار جمع می‌شود، پس این سیگنال در عمل همیشه خاموش است؛ برای سازگاری schema حفظ و صادقانه مستند شده.
- **«این اعداد را از کجا باور کنیم؟»** — کل زنجیره با seed ثابت بازتولیدپذیر است: `dataset` → `train` → `benchmark` → `visualize`؛ نتایج خام ۱۰۰ ردیفی هم در repo است.

## دستورات پشتیبان CLI (اگر خواستند کد را زنده ببینند)

```bash
python -m wumpus validate --input data/maps/example.txt
python -m wumpus run --agent search --input data/maps/example.txt
python -m wumpus run --agent rules --input tests/fixtures/golden2_pit.txt --trace
python -m wumpus visualize      # بازساخت کامل دمو از کد → docs/demo/index.html
```

در trace عامل قاعده‌محور، یک نمونهٔ `NO_BREEZE` → استنتاج `SAFE` → انتخاب frontier را نشان دهید — همان چیزی که در MIND LOG دمو دیدند، این بار مستقیم از ترمینال.
